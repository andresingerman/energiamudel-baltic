## Research pass Q4 (engine/storage), 2026-09-24
Measured (scratchpad/wasm-spike/bench.mjs, highs-js 1.15, M1, Node): daily LP 3 zones ~1250 vars 7.6 ms/block ->
2.8 s/yr single thread; weekly ~8700 vars 52 ms -> 2.7 s/yr. 4 workers -> ~0.7-1 s. v3: 0.2 s no storage,
0.6-0.9 s with fixed point. highs.wasm 3.4 MB.
Data: ENTSO-E installed battery 2026 EE 218 / LT 426 / LV 90 / FI 244 MW. Observed EE discharge Jun25-Aug26 median
127 MWh/day (~0.3 cycles/day). TSO 2035: Elering 1500 MW/3000 MWh, ERAA NT EE 1500 / LT 1750 (+Kruonis 938) / LV 500,
Litgrid 3.1-4.4 GW, Fermi presets 1.1-1.2 GW x4h. Reserves = majority of BESS revenue today (EE mFRR 58 % Jun 2026).
Literature: price-taker DP + damped fixed point defensible if convergence & residual reported (Enerallt adaptive bids,
PowerGAMA storage values, Denholm modified price-taker, Torralba-Diaz slow convergence on storage). LP = exact
competitive equilibrium. DA-only LP overstates storage today -> cycle cap / delta needed anyway. Horizon: daily OK
for 2-4h batteries (-2..4.5 %), wrong for Kruonis (weekly). Brown et al. 2024: SoC-based storage bids inside
merit-order clearing = clean alternative to iteration.
Candidate D: bisection core + storage as price-responsive bids (single re-clear, SoC tracked) + offline LP reference
golden test (Python v4 / highs-js Node).
- D4 Engine (D): hourly bisection clearing on the tree (0.2 s) + storage as price-responsive bids after one DP pass
  (delta, cycle cap, SoC tracked, no fixed-point iteration) + Kruonis/Daugava weekly storage value + OFFLINE LP
  reference (HiGHS; Python v4 or highs-js Node) with published heuristic-vs-LP gap table incl. GW-scale scenarios;
  fallback path = LP in workers (~1 s measured).
- D5 Reserves: upward reserve held out of DA per zone (v4 D-055/D-057 principle). Params: 2025 calibration = BTD
  hourly procured; 2026+ = Elering demand (FCR 28, aFRR 96-120, mFRR up 580-604 Baltic-wide); FCR+aFRR on batteries,
  mFRR split battery/thermal (default 50 %, flagged estimate); TSO-owned batteries (Energy Cells 200, AST 80) out of
  DA fleet to 2028; battery DA power = installed - reserved, then delta + cycle cap. Check: EE ~0.3 cycles/day.
- R-PROV (cross-cutting, Andres 2026-09-24): every input records what and where from, with link, for independent
  re-check; every literature justification cited with DOI link and full reference.
- D6 SMR: 0-3 units x 315 MW (owner; GE Vernova states 300 MWe net -> discrepancy to document, needs a citable
  Fermi source or "owner assumption" label). Plant operates under CfD strike 90 EUR/MWh (default). Dispatch follows
  contract: plain two-sided CfD -> produces whenever price > floor (must-run down to min load); with negative-price
  clause (no top-up at p<=0, v4 D-061) -> curtails to min load at p<0. Min load & variable cost = sourced editable
  params. Planned outage per unit in least-needed window (duration sourced), forced outages MC only. Paired runs +
  CfD card (hourly, monthly, collar) kept.
